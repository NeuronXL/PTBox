# PTBox 1.1.1

- 修复检查更新将所有 HTTP 403 都误报为 GitHub 限流的问题。现在分别提示访问拒绝、确认限流、服务错误和网络连接失败。
- 确认限流后显示可重试时间，并保存冷却状态；重复点击或重启应用不会在冷却期间继续发送请求。
- 区分“暂无正式版本”和“当前已是最新可用版本”；检查正式版本返回 404 时额外确认仓库可访问。
- 检查及下载失败记录 HTTP 状态、限流响应头和 GitHub 请求标识，便于排查网络问题。不会将服务器 HTML 错误页显示到界面。

可关闭 PTBox 后覆盖安装到原目录，保留应用与设置。安装包包含运行环境，无需另装 .NET；另提供自包含便携 ZIP。

源码重新通过 Release 构建（0 警告、0 错误）和 26 组测试。安装包使用已归档并核验的 1.1.1 签名发行物，便携 ZIP 从本次源码重新构建。真实跨版本安装升级及失败恢复仍待干净 Windows 环境验收。

安装包尚未配置 Windows Authenticode 代码签名；应用内更新验证 RSA-PSS 签名清单及 SHA256。1.0.x 用户需先手动安装接入版。
