# PTBox 1.1.2 · 升级测试版

此版本用于验证 1.1.1 → 1.1.2 的应用内更新流程，功能与配置格式保持不变。

## 测试步骤

1. 在已安装的 PTBox 1.1.1 中打开“设置 → 关于与更新 → 检查更新”。
2. 确认可用版本为 1.1.2，点击“下载更新”，等待下载和校验完成。
3. 点击“重启 PTBox 更新”，确认保存设置并安装。
4. 新版启动后确认版本为 1.1.2，检查原应用列表、顺序、主题、壁纸与设置是否保留。
5. 再次检查更新，应提示当前已是最新可用版本。

请使用安装版测试；便携版只能检查和下载，需要手动安装。整个过程只重启 PTBox，不重启 Windows。

当前客户端忽略 GitHub 预发布，因此本升级测试版本需通过正式 stable Release 提供。发行附件须包含完整安装包、SHA256、update.json 和使用原有发布密钥生成的 update.json.sig。
