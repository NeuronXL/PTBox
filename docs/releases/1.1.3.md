# PTBox 1.1.3

新增从桌面快捷方式添加软件，并修正更新安装包的大小显示。

## 新增

- “添加应用 → 本地程序 / 桌面快捷方式”支持 EXE、LNK 和 URL 文件。
- 文件选择器默认打开桌面，新增“公共桌面”入口，可找到为所有用户安装的软件快捷方式。
- LNK 由 Windows 按原快捷方式打开，保留原启动参数、工作目录和图标；URL 自动识别网页和游戏等应用协议地址。
- 编辑已有入口的程序路径时也可选择快捷方式。

LNK 入口保留原快捷方式路径，添加后请保留该文件；移动或删除后需重新选择。快捷方式默认直接打开，不等待退出或强制复用进程。

## 修复

- 安装包大小使用与换算方式一致的 MiB 单位，并固定使用小数点，例如 `100.4 MiB`。

## 更新

安装版可在“设置 → 关于与更新 → 检查更新”中下载安装，随后选择“重启 PTBox 更新”。沿用原发布签名密钥，支持从 1.1.1 或 1.1.2 更新。便携版请下载 ZIP 并手动更新，保留个人配置。

大小显示修复在升级到 1.1.3 后生效，旧版本下载本次更新时仍使用旧显示格式。

已通过 27 组测试，覆盖真实快捷方式启动、参数与工作目录保留、图标读取、添加对话框及更新校验。特殊商店应用和第三方游戏启动器尚未逐一实机验收。
