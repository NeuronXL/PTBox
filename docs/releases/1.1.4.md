# PTBox 1.1.4

修正桌面快捷方式导入方式，改善文件选择器的扫描和显示性能。

## 快捷方式

- 选择 LNK 后，保存实际 EXE、原启动参数、工作目录和管理员运行标志。
- 图标直接读取 EXE，不再显示快捷方式角标。
- 新导入的入口不再依赖原 LNK；删除或移动桌面快捷方式后仍能启动程序。
- 无法解析成 EXE 的特殊快捷方式会显示明确提示，可改选程序本身或网页、游戏的 URL 快捷方式。

对于 1.1.3 已添加的 LNK 入口，请在“设置 → 应用管理”中选中入口，浏览并重新选择一次快捷方式，然后保存。无需删除重建；原快捷方式已丢失时，请选择实际 EXE 并核对启动参数。

## 文件选择性能

- 减少重复文件属性查询，批量刷新列表，只创建可见行。
- 初始路径检查和所选快捷方式解析放到后台，支持超时与取消。
- 切换目录或关闭窗口时取消过时扫描，避免旧结果覆盖新目录。

## 更新

安装版可在“设置 → 关于与更新 → 检查更新”中下载，随后选择“重启 PTBox 更新”。沿用原发布签名密钥。便携版请下载 ZIP 并手动更新，保留个人配置。

已通过 27 组测试，覆盖删除原快捷方式后的实际启动、中文参数和工作目录保留、EXE 图标，以及 3,000 文件列表的批量刷新、虚拟化和导航。网络盘和同步目录的实际速度仍取决于运行环境。
