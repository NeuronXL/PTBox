# PTBox 1.1.0

- 设置新增“关于与更新”，可检查正式版本、查看说明、下载并验证安装包。
- 安装版支持保存设置后重启 PTBox 完成升级，不重启 Windows，不关闭游戏或 Moonlight。
- 安装版个人配置迁移到 LocalAppData/PTBox；保留迁移备份、应用顺序和图片资源。
- 发布清单使用 RSA-PSS 签名，安装包验证大小和 SHA256。
- 便携版提供更新检查、下载和手动安装引导。

现有 1.0.0 / 1.0.1 用户需手动安装本接入版一次，后续才能使用应用内更新。

此目录为本地待发布材料，尚未上传。在线升级的 GitHub 实机验收待正式发布后完成。
