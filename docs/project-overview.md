# 项目概况与当前能力

> 本文保留 1.0.0 产品基线。1.1.1 已实现签名更新、独立更新器和配置迁移；当前安装与下载请见 [README](../README.md)，更新行为见 [发布操作](release-operations.md)。下文“未实现”仅描述旧基线。

基线日期：2026-09-22。状态：本地可用，已交付安装包 1.0.0，在线更新待实现。

## 1. 产品定位

PTBox 是个人客厅 Windows PC 的大屏入口，用于在电视上通过飞鼠、遥控器的键盘映射、鼠标或键盘打开应用、串流客户端和网站。游戏管理由 Steam / Playnite 等应用负责。

核心目标：远距离可读、方向键可操作、应用退出后容易回到首页，同时保留正常 Windows 桌面和系统操作。当前不接入账号、云数据库、游戏元数据、封面库或社交功能。

技术基线：C#、.NET 8、WPF、Windows 11 x64、少量 Win32 P/Invoke。运行代码没有第三方 NuGet 包；安装工具 Inno Setup 为开发时依赖。安装版自带 .NET 运行环境。

## 2. 首页规则

| 区域 | 当前行为 |
| --- | --- |
| 分类栏 | 首页和全部应用始终存在；游戏、串流、影视只在有对应应用时显示 |
| 推荐区 | 按配置顺序取前三个应用；名称和启动目标来自真实配置，没有自动轮播 |
| 推荐分页 | 至少两个推荐应用才显示圆点 |
| 应用栏 | 使用用户配置的应用；末尾始终提供“添加应用”；超出屏幕可横向滚动 |
| 快捷区 | 按应用顺序取前两种不同分类的首项，并保留桌面入口；空配置显示添加引导 |
| 底栏 | 设置、桌面、电源等系统操作，不依赖用户应用列表 |
| 空首页 | 引导添加应用；不会重新填入示例应用，也不保留已删除应用的推荐入口 |

删除应用、改名、调整顺序、修改分类并保存后，首页立即刷新。当前分类删除至空时回到首页。历史配置中仍存在的应用会保留，常规加载不会按品牌或 ID 删除用户条目。

## 3. 添加与管理应用

- Steam Big Picture 与 Moonlight 作为可选模板，检测常见路径、提示安装状态；不会下载或安装第三方软件。
- 模板已添加时禁用重复添加；删除后可重新添加。
- 其他入口可通过本地 EXE、网页建立，并在设置中配置应用 URI。
- 可编辑名称、副标题、分类、路径、参数、图标、启动行为、进程复用及排序；最多 99 个应用。
- 添加和编辑先进入草稿；保存才写入磁盘并刷新首页，返回取消不修改原配置。

应用卡片使用统一深色底，图标优先使用自定义图片，再尝试程序原图标、注册协议图标或网站图标，最后使用通用图标。没有按品牌名称绘制的替代图标。

## 4. 启动与返回

| 类型 / 设置 | 行为 |
| --- | --- |
| EXE | 解析路径后启动，可按完整 EXE 路径复用已运行进程 |
| HTTP(S) URL | 使用系统默认浏览器打开 |
| 应用 URI | 交给 Windows 已注册的协议处理程序 |
| `waitForExit` | 等待启动或复用的进程退出，然后恢复首页和选择 |
| `fireAndForget` | 仅打开；用热键或再次运行 Launcher 返回 |

一次只跟踪最近一次等待退出的进程。切换跟踪或关闭 Launcher 不会终止被打开的应用。PWA、浏览器、多窗口常驻进程以及启动后立即交接给子进程的应用，应优先使用 `fireAndForget`。

Ctrl+Alt+H 注册为全局返回热键；若注册失败有状态提示。按用户 SID 实现单实例，再次运行会唤回现有实例。桌面入口最小化 Launcher，不替换 Windows Shell。

## 5. 输入和视觉约定

方向键导航、Enter / Space 确认、Esc / Backspace / BrowserBack 返回。首页返回不会退出，Alt+F4 或电源菜单中的退出会关闭 Launcher。F11 临时切换全屏，默认在主显示器全屏显示。

文本框中左右键和 Backspace 编辑内容，上下键离开单行字段；下拉菜单打开时返回先收起菜单。程序、图标、壁纸使用同风格的文件选择器，支持常用目录、磁盘、筛选和粘贴路径。

视觉使用山景、深色半透明圆角面板、白色焦点和胶囊按钮。首页与设置共用四瓣描边方向键图标。添加、文件选择、操作确认和电源弹窗共用样式。首页采用 1600×900 逻辑画布和等比缩放，非 16:9 屏幕留边。

## 6. 系统集成与交付

- 默认不开启登录启动；用户在设置中开启后写入当前用户 HKCU Run。
- 电源菜单提供返回、关机、重启、退出；关机/重启二次确认，默认取消，不强制结束应用。
- 便携版：`artifacts/PTBox-win-x64/`，复制完整目录使用。
- 安装版：`artifacts/installer/PTBox-Setup-1.0.0-win-x64.exe`，当前用户安装、中文深色向导、开始菜单和可选桌面快捷方式、可卸载。
- 现有安装器可覆盖升级并保留配置；卸载保留个人数据，只清理指向自身安装位置的自动启动项。
