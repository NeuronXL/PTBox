## 当前状态

- 已有可运行便携版与中文版安装包；应用管理、启动返回、设置、统一弹窗均已实现。
- 新配置为空；Steam / Moonlight 是用户主动添加的模板，不是固定预置应用。
- 已实现设置中的版本检查、签名下载和独立安装更新程序；1.0.x 用户先手动安装一次接入版。
- 源码与发行仓库为 `NeuronXL/PTBox`；本地签名打包与 GitHub 正式发布分别执行。
- 本地测试与真实升级验收分别记录，后者尚待干净环境和实际发布，见 [ROADMAP.md](../ROADMAP.md)。

## 文档维护规则

1. 新能力先在路线图中标记状态，完成并验证后再移入“已实现”。
2. 改动配置格式时同步更新字段说明、迁移策略和兼容性测试，不能仅修改示例 JSON。
3. 发布版本号、配置 `version` 和将来的更新清单 `schemaVersion` 是三个不同概念。
4. 更新安装包验证记录时写明被测文件的版本、SHA256 和报告路径；重打包后不能沿用旧校验值。
5. 设计概念图可能保留早期视觉方案；实际功能以项目概况、代码及最近一次验证为准。
