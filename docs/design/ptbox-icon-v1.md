# PTBox 应用图标 · v1

![PTBox 图标](ptbox-icon-v1.png)

方向：字母 P 的上半部融合电视屏幕，内部以琥珀色播放符号表达客厅娱乐入口。深蓝圆角底座与暖白主体呼应 Launcher 的蓝调背景和暖光元素。

生成方式：内置 image_gen 工具，透明背景 PNG。此版本作为图标设计稿保存，尚未替换应用的 EXE 图标。

## 最终提示词

Use case: logo-brand.
Asset type: a single finished Windows desktop application icon for PTBox, a personal living-room television launcher for games, streaming, films and Windows apps.
Design one distinctive, beautifully resolved symbol: a bold sculptural capital P whose rounded upper bowl subtly suggests a television screen, with one small warm amber right-pointing play triangle inset in that screen. The P must read immediately as a P, with a substantial vertical stem and a generous open lower right. One coherent logo, not a collage of objects.
Style: premium restrained Windows 11 app icon, front-facing orthographic composition, rounded geometry, subtly beveled ceramic and frosted-glass surfaces, carefully controlled soft depth. A midnight navy rounded-square tile with a subtle desaturated blue gradient; large warm ivory P monogram; a rich warm amber play accent. Quiet refined highlights, high contrast, no excessive gloss. Match an elegant blue-hour mountain-and-cabin media launcher, without depicting any landscape inside the icon.
Composition: square 1024x1024 canvas; one centered rounded-square tile occupying about 86 percent of the canvas; logo fills about 65 percent of the tile. Perfectly frontal, optically balanced, broad simple forms legible at 32px. Transparent alpha background outside the rounded tile, clean antialiased edges, minimal shadow fully inside canvas.
Constraints: a single icon only; no words, no caption, no PTBox wordmark, no presentation board, no multiple variants, no mockup device, no extra decorations, no mountains, no tiny buttons, no perspective tilt, no neon cyberpunk glow, no watermark. Deliver the actual isolated icon asset.
